## 2026-09-09 · (해시 미정) · feature: visit note cards with rating dots, compare picker and sticky header

**영역**: 홈 임장기록 · 매매 탭 노트 카드 · 단지 상세 노트 카드 · 임장노트 편집 · 임장 단지 비교 (기획서 v6 반영)
**사용자 관점 변경**:
- 홈 “최근 임장”이 목록 행 → **가로 슬라이드 카드**. 카드: 단지명 / 한 줄(`09.04 방문 · 점검 4/4` 또는 강조색 `기록 미완 · 마저 채우기` 또는 코발트 `09.12 방문 예정`) / 채광·주차 점. 상한(3)을 넘으면 “더 보기” 카드 → 매매 탭. 메모는 싣지 않는다.
- 노트 카드(매매 탭·단지 상세): 단지명·방문일 → 메모 2줄 → 구분선 → **항목별 점 5개**(채광·소음·주차·관리, 매긴 것만) → 칩(`역 도보 8분`, 본 매물, `방문 당시 12억 1,500`, 엘리베이터 붐빔/없음, 누수 있음). 숫자 나열 칩 삭제.
- **점 표기 공통 규칙**: 1~5점을 점 5개로, **2점 이하는 붉은색**. 홈·카드·비교표 모두 동일.
- 임장노트 편집기 맨 아래에 읽기 전용 “방문 당시 실거래” (`84.9㎡ · 12억 1,500`, 스냅숏에 금액 있을 때만).
- 비교 화면: 단지 선택이 칩 → **체크박스 행**(단지명 / `2026.07.20 · 84㎡ · 12층`). 표 머리글(단지명 + 본 매물)은 **스크롤해도 고정(sticky)**. 점수 칸은 숫자 없이 점만, 우세는 배경 틴트. **메모는 표에서 빼서 표 아래 단지별 블록**으로.
**데이터·API**: 없음
**네비게이션**: 없음
**문구**: `note_criterion_management_short` 관리 · `note_reference_short` 방문 당시 %1$s · `home_visit_more` 더 보기 · `home_visit_incomplete` → “기록 미완 · 마저 채우기”(짧게)
**규칙·엣지케이스**: 홈 카드는 채광·주차 두 항목만(미평가면 빈 점). 비교 표에서 메모 없는 단지는 메모 블록 없음.
**iOS 체크리스트**:
- [ ] 공용 `RatingDots(score)` — 5점 만점, ≤2 붉은색
- [ ] 홈 최근 임장 가로 스크롤 카드 + 더 보기
- [ ] 노트 카드 레이아웃(메모 → 점 → 칩)
- [ ] 편집기 “방문 당시 실거래” 읽기 전용
- [ ] 비교: 체크박스 선택, sticky 헤더, 점만, 메모 블록

## 2026-09-09 · (해시 미정) · fix: parse K-apt facility strings by category

**영역**: 매매 › 단지 상세 › 주변 시설
**사용자 관점 변경**: 교육·편의 시설이 칩 나열이 아니라 **분류 | 이름** 행으로 보인다 (`초등학교 | 구암, 신봉, 은천초등학교`). `공원()` 같은 빈 항목과 전화번호가 사라진다. 단지 내 시설은 그대로 칩이고 `기타`는 뺀다.
**데이터·API**: API 변경 없음. K-apt 원문 파싱 규칙만 변경 —
- `convenient_facility` / `education_facility`: `분류(내용) 분류(내용) …`. **괄호 깊이를 세며 최상위 공백에서만** 끊는다(괄호 안에 공백·쉼표·전화번호·중첩 괄호가 온다). 괄호 안 쉼표(`,`/`，`/`/`)는 같은 분류의 여러 이름. 전화번호(`031-5189-4951`, `1522-2500`, 감싼 괄호 포함)는 삭제. 빈 괄호면 항목 삭제. 같은 분류는 하나로 합침.
- `welfare_facility`: 쉼표 분리, `기타` 삭제.
- 도메인: `Surroundings.convenient/education: List<FacilityGroup(category, names)>`, `welfare: List<String>`.
**네비게이션**: 없음
**문구**: 없음
**규칙·엣지케이스**: 닫는 괄호가 없어도 마지막 조각은 살린다. 분류만 있고 괄호가 없으면 버린다. 실측 샘플은 `FacilityParserTest` 참고.
**iOS 체크리스트**:
- [ ] 시설 파서를 위 규칙으로 교체 (테스트 7개 케이스 그대로 옮기면 됨)
- [ ] 단지 상세 주변 시설: 교육·편의는 행(분류/이름), 단지 내는 칩

1. 요약

청년의집은 이용자의 개인정보를 수집하지 않습니다.

회원가입·로그인이 없고, 이름·연락처·이메일·위치·연락처 목록·사진 등 어떤 개인정보도 요구하지 않으며, 광고 식별자나 분석(Analytics) 도구도 사용하지 않습니다.

앱이 저장하는 정보는 이용자가 직접 고른 화면 설정(관심 지역, 공고 분야)뿐이며, 이 값은 이용자의 기기 안에만 저장되고 외부로 전송되지 않습니다.

2. 수집하지 않는 정보

앱은 다음 정보를 수집·저장·전송하지 않습니다.

  • 이름, 생년월일, 성별, 전화번호, 이메일 주소 등 이용자를 식별할 수 있는 정보
  • 계정 정보 (회원가입·로그인 기능이 없습니다)
  • 위치 정보 (GPS·네트워크 위치 권한을 사용하지 않습니다)
  • 연락처, 사진, 파일, 통화·문자 기록
  • 광고 식별자(AAID), 기기 고유 식별자
  • 앱 사용 이력, 화면 조회 로그 등 행태 정보

3. 기기에만 저장되는 정보

항목저장 내용저장 위치목적
관심 지역 지역 코드(예: 11) 기기 내부 저장소
(Jetpack DataStore)		 홈·임대공고 목록을 선택 지역으로 필터링
공고 분야 공공임대 / 공공분양 구분값 기기 내부 저장소
(Jetpack DataStore)		 공고 목록의 기본 분야 지정
  • 위 값은 앱 개발자를 포함한 누구에게도 전송되지 않습니다.
  • 앱은 Android 자동 백업(allowBackup)과 기기 간 데이터 이전(dataExtractionRules)을 모두 비활성화하고 있어, 이 값이 클라우드에 백업되거나 다른 기기로 옮겨지지 않습니다.
  • 앱을 삭제하면 위 값은 기기에서 함께 삭제됩니다. 별도의 삭제 요청 절차가 필요하지 않습니다.

4. 외부 서비스와의 통신

앱은 임대·분양 공고 정보를 보여주기 위해 아래 외부 서비스에 조회 요청을 보냅니다.

  • 공공데이터포털 오픈 API (https://apis.data.go.kr, 한국지능정보사회진흥원 운영)
    • 원 데이터 제공: 국토교통부 마이홈포털
    • 전송 항목: 앱에 내장된 서비스 인증키, 조회 조건(지역 코드, 공고 분야, 페이지 번호 등)
    • 이용자의 개인정보는 전송되지 않습니다.

다만 인터넷 통신의 일반적인 특성상, 요청 과정에서 이용자의 IP 주소·접속 시각 등 통신 기록이 해당 서비스 운영 주체의 서버에 남을 수 있습니다. 이 기록은 앱 개발자가 수집하거나 열람할 수 없으며, 그 처리는 공공데이터포털의 개인정보처리방침을 따릅니다.

5. 외부 링크 이동

공고 상세 화면에서 원문 링크를 선택하면 기기의 기본 웹 브라우저로 해당 기관의 공고 페이지가 열립니다. 이후의 개인정보 처리는 앱이 아닌 해당 사이트의 개인정보처리방침이 적용됩니다.

6. 앱이 요구하는 권한

  • android.permission.INTERNET — 공고 정보를 내려받기 위한 인터넷 접근

이 권한은 설치 시 자동으로 부여되는 일반 권한이며, 별도 동의를 요구하는 런타임 권한(위치·카메라·저장소·알림 등)은 사용하지 않습니다.

7. 제3자 제공 및 위탁

앱은 수집하는 개인정보가 없으므로, 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 또한 광고 네트워크·분석 SDK·크래시 리포팅 도구 등 제3자 SDK를 포함하고 있지 않습니다.

8. 개인정보의 보유 및 파기

수집하는 개인정보가 없으므로 보유·파기 대상 정보가 존재하지 않습니다. 기기에 저장된 설정값은 앱 삭제 시 함께 제거됩니다.

9. 이용자의 권리

이용자는 언제든지 앱의 [설정] 화면에서 저장된 관심 지역·공고 분야를 변경할 수 있으며, 앱을 삭제하는 것만으로 기기에 저장된 모든 값을 완전히 삭제할 수 있습니다. 앱 개발자가 보관하는 이용자 정보가 없으므로 별도의 열람·정정·삭제 요청 절차는 두고 있지 않습니다.

10. 아동의 개인정보

앱은 만 14세 미만 아동을 포함한 어떠한 이용자로부터도 개인정보를 수집하지 않습니다.

11. 안전성 확보 조치

  • 외부 통신은 모두 HTTPS(TLS)로 암호화하여 이루어집니다.
  • 배포 빌드에는 코드 축소·난독화(R8)를 적용합니다.
  • 기기에 저장되는 설정값은 앱 전용 저장 영역에 보관되어 다른 앱이 접근할 수 없습니다.

12. 처리방침의 변경

법령·서비스 내용의 변경으로 이 처리방침을 수정할 경우, 변경된 내용과 시행일을 이 문서에 명시하여 공지합니다. 이용자의 권리에 중대한 영향을 주는 변경은 시행일로부터 최소 7일 전에 공지합니다.
